# Install in ChatGPT

1. Open **Settings → Apps & Connectors** (Developer mode may be required — enable it under Settings → Apps & Connectors → Advanced).
2. Click **Create** (Add connector).
3. Choose **MCP Server**, paste URL: `https://mcp.narracore.app/mcp`
4. Save and enable the connector. No authentication needed for the free tier.
5. In a new chat, enable the connector (＋ icon → search "Narracore Screenplay Formatter"), then:

   > 把下面这段粗稿排成标准剧本并给我 PDF：……

Note: ChatGPT's connector UI changes frequently; if you don't see "Create", make sure Developer mode is on.

## Using a paid license key

Paste it into chat when asked: `授权码 NRC-XXXX-XXXX-XXXX-XXXX`. Top-ups land on the same key.
