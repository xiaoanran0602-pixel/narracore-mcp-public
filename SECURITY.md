# Security Policy

## Reporting a vulnerability

Found a security issue with the Narracore Screenplay Formatter service (narracore.app / mcp.narracore.app)?

Email **huiyicd@foxmail.com** with details and reproduction steps. Please do not open public issues for security reports.

We aim to respond within 72 hours.

## Scope

- The hosted MCP endpoint `https://mcp.narracore.app/mcp`
- The checkout / license key flow at `https://narracore.app`

## Non-goals

This repository contains documentation and registry metadata only — source code is kept private. Reports about third-party MCP clients are out of scope.
